把博客搬回自己的院子

在别人的广场上住了太久，我想重新拥有一块可以自己决定如何生长的地方。

文 / Waveadwake 2026 年 9 月 28 日 8 分钟阅读 随笔

上周收到一封域名续费提醒。那是我很多年前注册的一个域名，用过一段时间，后来荒废了。邮件很短，却让我在桌前坐了很久：原来我也有过一块自己的地方，只是很久没有回去了。

这几年，我把大部分文字发在社交平台上。它们被看见得很快，也被忘记得更快。久而久之，我几乎要以为，写作本来就该是这个样子。

商场与院子

我无意把平台说成敌人。那里仍然有很好的读者，也有我喜欢的作者。平台像一座热闹的商场：灯很亮，人很多，你随时可以支起一张桌子，把自己的东西摆出来。

但商场有商场的规则。它决定什么样的招牌更显眼，什么时间段人流最多，也决定你的摊位会不会在某个清晨被悄悄挪到角落。你在那里留下很多东西，却很难说哪一块地真正属于你。

博客更像一个院子。门口没有推荐算法，也没有滚动的信息流。你种什么，它就长什么；你很久不回来，它就安静地荒着。有人偶然推门进来，坐下来读完一篇文章，这已经足够。

拥有一个地方，不只是拥有一个网址，而是拥有决定“什么值得被留下来”的权利。

为什么又想起博客

真正让我想回来的，不是对平台的厌倦，而是一种越来越强的失重感。

帖子发出去之后，我会反复刷新，看有没有新的赞和评论。数据好的时候，觉得自己说对了什么；数据差的时候，又忍不住怀疑文字本身。写作变成了一场持续的打分，而分数并不掌握在自己手里。

我还发现，自己开始不自觉地按照平台喜欢的方式说话：短句、结论、情绪先行的标题。那些绕远路的、暂时没有答案的、需要读上十分钟的念头，慢慢被我留在了备忘录里。

我想重新练习另一种写法。不为完播率，不为转发量，只为了把一件事想清楚。

这次，选一条简单的路

我给自己定了三个条件：打开要快，维护要少，十年后还能看懂。

所以这个站点没有框架，没有数据库，也没有需要定期升级的插件。它只是一些 HTML 文件、一张样式表、几十行 JavaScript，以及一个放图片的文件夹。

目录 structureblog/
├── index.html
├── posts.html
├── post/
│   ├── slow-is-a-skill.html
│   └── blog-return.html
├── assets/
│   ├── css/style.css
│   ├── js/site.js
│   └── images/
├── feed.xml
├── sitemap.xml
└── .nojekyll

托管在 GitHub Pages 上。把文件推到仓库，站点就更新了；不写东西的时候，它也不会产生任何费用。没有构建步骤，意味着我随时可以打开一个文件，改几个字，然后合上电脑。

这当然不是唯一的选择，也未必是最好的选择。静态站点有它的边界：没有评论、没有后台、不能即时搜索整个互联网。但对我而言，这些“没有”反而让事情变得清楚。我只需要一个能安静放文字的地方。

发布，只需要一次 push

写完一篇文章之后，我要做的事只有三件：改文件、提交、推送。

terminal# 在站点目录里
git add .
git commit -m "post: 把博客搬回自己的院子"
git push

剩下的交给 GitHub Actions。一两分钟后，新的页面就会出现在网址上。这个过程有一种朴素的确定感：我写下什么，世界就多出什么，中间没有太多别的东西。

写作流程：从草稿到发布

工具变简单之后，写作的流程也短了。我通常在纯文本文件里打草稿，想到哪里写到哪里。第二天再读一遍，删掉那些只是为了显得聪明的句子。

这一步往往最花时间。删掉一段话的时候，我会问自己：它是真的有必要，还是只是舍不得？多数时候，答案是后者。

然后才是排版：加上标题、分段、配一张自己画的图。图片不追求精致，够用就好。最后检查链接、更新日期，推送。没有预览按钮，也没有发布倒计时。点下回车之后，文章就安静地待在那里了。

START SMALL / 如果你想试试

不必先买域名，也不必研究一整套建站工具。从一个只有首页和文章的静态页面开始，先写三篇。能持续写下去，比用什么技术重要得多。

院子需要慢慢长

搬回来之后，我并没有立刻写出很多文章。更多的时候，我只是打开站点，换一张图，修一句读起来别扭的话，然后在院子里坐一会儿。

这大概就是“自己的地方”的意义。它不要求你持续生产，也不因为你沉默就降低权重。你来，它就在；你不来，它也不催。

等再过几年，这里也许会多出一些文章，几本读书笔记，或者一条关于某次散步的路线。它们不一定重要，但会是我真正想留下的东西。

如果你也有一个荒废很久的域名，或者一个只写了两篇的博客，不妨找个下午回去看看。院子不会怪你离开太久。

写于杭州，窗外正在下雨。
